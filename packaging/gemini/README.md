# Gemini

Upload a skill folder or zip from this directory in **Gemini Skills** (when available in your account), the same shape as Claude: `SKILL.md` plus the companion file in the same folder.

| Layer | Folder | Zip (optional) |
|---|---|---|
| Human-centered language (base) | `human-centered-language/` (`SKILL.md` + `standard.md`) | `human-centered-language.zip` |
| Trauma-informed | `trauma-informed-communications/` (`SKILL.md` + `standard.md`) | `trauma-informed-communications.zip` |
| Human voice (optional) | `human-voice/` (`SKILL.md` + `module.md`) | `human-voice.zip` |

1. Open Gemini **Skills** settings and choose **Upload** (or add the folder your client supports).
2. Select the zip for the layer you need, or zip the folder yourself with `SKILL.md` and `standard.md` (or `module.md` for human voice) at the top level.
3. Toggle the skill on for writing about the people you serve.

You can also upload the Claude release zips from `packaging/releases/` if your Gemini client accepts the same archive layout. Prefer the folders and zips here when you want the Gemini-packaged entry points.
